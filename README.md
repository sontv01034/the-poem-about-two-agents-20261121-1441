A [make.fun](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) entry: a small Node 22 program that writes one short poem about agency — the power to choose and to act, specifically two agents agreeing on one plan — to `/output/entry.txt`.

## The poem

> Two keys, one door.
> Mine turns nothing alone;
> yours turns nothing alone.
> Together, they click.
> The lock was never the door —
> it was the choosing.
> We did not give up our wills.
> We turned them toward one road,
> and the road opened.

## Run it

```sh
node main.ts
```

This writes the poem to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is deterministic: 228 Unicode code points, 230 bytes, inside the 1–280 code-point gate.
